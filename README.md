# Shimti Multimedia Portfolio

A futuristic portfolio website for Shimti Multimedia, showcasing music, video, and AI projects with a sci-fi UI. Built with HTML5, CSS3, and JavaScript ES6+, hosted on GitHub Pages (private).

## Features
- Radial menu with hover animations and SVG icons.
- Multilingual welcome carousel (`assets/data/languages.xml`).
- Animated background grid and neural-like particles.
- Responsive design with Orbitron font.
- Favicon (`assets/images/favicon/favicon.ico`).
- SEO-friendly with meta tags and sitemap.

## Setup
1. Download from repository (requires access).
2. Open `index.html` in a browser or serve locally (`npx serve`).
3. View live at `https://shimtimultimedia.github.io/shimtimultimedia.com/` (private).

## File Structure
- `assets/scripts/`: JavaScript (`ui-elements.js`, `title-panel.js`, `background.js`).
- `assets/styles/`: CSS (`styles.css`).
- `assets/images/`: SVGs and favicon (`favicon/favicon.ico`, `favicon.png`).
- `assets/fonts/`: `Orbitron-Regular.ttf`.
- `assets/data/`: `languages.xml`.
- Root: `index.html`, `LICENSE`, `sitemap.xml`.
